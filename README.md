# custom-checks-examples

Examples of scripts that report custom check outcomes using
[Meticulous](https://www.meticulous.ai/) and the
[`@alwaysmeticulous/custom-checks`](https://www.npmjs.com/package/@alwaysmeticulous/custom-checks)
SDK.

## Examples

| Example | Description |
| ------- | ----------- |
| [network-requests](./network-requests/) | Compare per-session network request counts on head vs. base and warn when capacity is exceeded |
